# Работа K2-04

- Код студента: Соня
- Что сделано: образ отправлен в локальный registry и получен из него обратно.

## Команды

```text
docker compose --profile registry up -d registry
docker tag devops-student:v1 localhost:5000/workshop:v1
docker push localhost:5000/workshop:v1
docker pull localhost:5000/workshop:v1
docker image inspect localhost:5000/workshop:v1
```

## Наблюдения

- Локальный registry запущен на `127.0.0.1:5000`.
- Образу добавлен тег `localhost:5000/workshop:v1`.
- `docker push` успешно отправил слои в registry.
- `docker pull` получил образ и подтвердил актуальность локальных слоёв.
- Digest из вывода push и pull:

```text
sha256:69179c2354170107492bc35fa87eddaf529a8be90d3d4df90dfc0cdfa2ebaa89
```

- `docker image inspect` показал `localhost:5000/workshop@sha256:69179c...` в `RepoDigests`.

## Вывод

Тег — удобное имя версии, которое можно переназначить другому образу. Digest вычисляется по содержимому и однозначно указывает конкретный вариант образа.

## Ответ на вопрос из задания

`docker push` только передаёт образ в registry. Контейнер не создаётся и приложение не запускается автоматически; для запуска нужна отдельная команда `docker run` или `docker compose up`.
