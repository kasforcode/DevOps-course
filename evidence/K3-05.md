# K3-05. Разбор лога pipeline

Ошибочный запуск: https://github.com/kasforcode/DevOps-course/actions/runs/44524542224

- событие: `push`;
- SHA: `f4d96df7569239defe99bf6c66914f0016fcfad0`;
- `test` завершился успешно, но `build` завершился с ошибкой.

В workflow временно был указан путь `lab/MissingDockerfile`. Содержательная причина
ошибки сборки — Docker не может открыть отсутствующий файл Dockerfile по этому пути.
Это ошибка входного пути сборки, а не ошибка тестового контракта: тесты проверяют
приложение и проходят независимо от наличия Dockerfile.

Путь исправлен обратно на `lab/Dockerfile`; итоговый workflow содержит правильный путь
и не изменяет тесты.
