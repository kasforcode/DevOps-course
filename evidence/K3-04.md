# K3-04. Сборка после тестов

В `Student CI` добавлен отдельный job `build` с `runs-on: ubuntu-latest` и
`needs: test`. Он получает исходники тем же checkout Action и выполняет:

```text
docker build -f lab/Dockerfile -t devops-student:${{ github.sha }} lab
```

Run с failed test и skipped build: https://github.com/kasforcode/DevOps-course/actions/runs/44524129140

- событие: `push`;
- SHA: `23500f3889a9208e2929c4faf5fc533502868fcc`;
- `test`: `failure`;
- `build`: `skipped`.

Исправленный run с успешными `test` и `build` в одном запуске:
https://github.com/kasforcode/DevOps-course/actions/runs/44524277655

- событие: `push`;
- SHA: `664302353c17d67191478de109c67d68953205e9`;
- `test`: `success`;
- `build`: `success`.

В обоих запусках команда сборки использует тег SHA run.

Сборка на временном runner не отправляет образ в registry, поэтому после завершения
runner образ там не остаётся. Сборка не является deployment.
