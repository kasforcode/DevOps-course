# Работа K2-05

- Код студента: Соня
- Что сделано: создана и устранена ошибка адреса API в `compose.student.yaml`.

## Команды

```text
docker compose -f compose.student.yaml up -d web
curl -i http://127.0.0.1:8080/api/requests
docker compose -f compose.student.yaml logs --tail=12 web
```

## Наблюдения

- При временном значении `API_URL=http://api:9999` запрос списка вернул `HTTP/1.0 503 Service Unavailable` и `{"error": "upstream_unavailable", ...}`.
- Лог web содержал событие `upstream_unavailable` с `target: "http://api:9999"` и ошибкой `Connection refused`.
- После возврата `API_URL=http://api:8000` и повторного `up -d web` список заявок снова открылся.
- После исправления создана заявка №6 с видом `software`.

## Вывод

API слушает внутренний порт 8000. При значении 9999 web пытается обратиться к порту, на котором API не работает, поэтому возвращает 503. Возврат правильного порта восстановил работу приложения.

## Ответ на вопрос из задания

Для обращения web к api внутри сети Compose нужен порт `8000`, потому что это порт приложения в контейнере API. Порт `8080` опубликован только для браузера на компьютере.
