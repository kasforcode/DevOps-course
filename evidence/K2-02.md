## Команды

```text
docker build -f lab/Dockerfile -t devops-student:v1 lab
docker image inspect devops-student:v1
docker run --rm -d --name student-web -p 127.0.0.1:8081:8000 -e ROLE=web devops-student:v1
curl -i http://localhost:8081/health
docker logs student-web
docker stop student-web
```

## Объяснение Dockerfile

- `COPY app.py index.html ./` помещает файлы приложения в образ.
- `CMD ["python", "app.py"]` задаёт команду запуска приложения.
- `RUN mkdir /data && chown 10001:10001 /data` создаёт каталог данных и передаёт его пользователю приложения.
- `USER 10001:10001` запускает приложение не от root.

## Ответ на вопрос из задания

`EXPOSE 8000` только документирует внутренний порт контейнера. Чтобы открыть приложение в браузере с компьютера, нужен параметр `-p`, который связывает порт хоста с портом контейнера, например `8081:8000`.
